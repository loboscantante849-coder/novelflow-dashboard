## 2. 已验证的吸引力信号

### 2.1 有效结构

1. **第一句直接给原文对白或决定性事实**。近月高曝光和高互动样本中，184/191 条以对白或引号句开头；这不是“模板必须对白”，而是第一句要让冲突已经发生。
2. **第一段出现具体物件/地点/身份**。地图、门、血迹、金属标签、会议桌、车、走廊等比“他们之间有化学反应”更有画面。
3. **第二段推进一个选择或代价**。表现好的帖子不是简介，而是“现在必须选什么、谁会先承担后果”。
4. **末尾用故事问题收束**。含问句的样本互动率约 0.785%，高于整体 0.515%；问句必须绑定剧情，不用泛问“你怎么看”。
5. **控制在 3-5 个短段、2-4 个情绪表情**。过长解释、机械桥句和重复 CTA 会稀释第一屏。

### 2.2 需要削弱的结构

- 醒来/闹钟/起床作为首镜头：6 条检测到此类开头，互动率约 0.271%，明显低于整体。
- 连续使用同一句“one line changes the air…”等机械桥句：历史样本中大量重复，虽有曝光，但互动和品牌感偏弱。
- 只写设定、不写动作：如“她是某某身份、他很危险”，缺少正在发生的选择。
- 同一文案复制到多个平台：平台受众和字幕节奏不同，尤其 TikTok 应更短、更直接。

## 3. 多文案策略库

每个账号每天两条，主副版本必须使用不同策略、不同章节证据和不同 CTA。

| 策略 ID | 结构 | 最适平台 | 核心要求 |
|---|---|---|---|
| `dialogue_verdict` | 原文对白 → 现场反应 → 关系代价 | Facebook / Reels | 第一句必须是可核对对白；第二句立刻给反应 |
| `object_reveal` | 物件特写 → 谁发现 → 发现改变什么 | Instagram | 适合门、信、戒指、标签、地图、手机证据；不从手机静止画面开始 |
| `public_power_shift` | 众人现场 → 权力动作 → 站队问题 | Facebook | 强调旁观者反应、公开羞辱或反击，不写泛泛“everyone was shocked” |
| `countdown_choice` | 截止时间/婚礼/离开窗口 → 只能选一边 | TikTok | 3-5 句短节奏；最后停在“她现在选什么” |
| `pursuit_intercept` | 逃离动作 → 被拦截/追上 → 关系边界 | TikTok / Reels | 第一镜头必须移动或阻挡，不用床上睁眼 |
| `reader_reaction` | “I was not ready for…” → 具体名场面 → 读者站队 | Instagram / TikTok | 只在确有强反转时用，不写空泛安利 |
| `identity_recognition` | 认出某人/某物 → 过去与现在碰撞 → 真相悬念 | Facebook | 适合身份反转、旧关系重逢；证据必须来自同一场景 |
| `sensory_cinema` | 天气/声音/材质 → 动作发生 → 情绪代价 | Instagram | 只保留 1-2 个感官细节，必须服务冲突 |

### CTA 轮换

- `Search code {CODE} in {APP} to continue the story.`
- `The next choice is waiting — search {CODE} in {APP}.`
- `Read the full scene free with code {CODE} in {APP}.`
- Facebook 只有允许归因的应用账号附 verified short link；Instagram/TikTok 不放 URL。
